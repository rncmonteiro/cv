# Ricardo Monteiro — Academic CV website

A restrained, responsive academic CV website generated from the October 2026 CV.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.

The website includes the entries in the CV's education, appointments, teaching, student supervision, research team, collaborations, projects, journal articles, conference papers, editorial activities, lectures, prizes, scientific committees, institutional roles, consultancy and languages sections. Personal date/place of birth are intentionally not reproduced on the public page. The complete original CV is included as a downloadable DOCX.

The page uses Google Fonts when available and falls back to system fonts. No tracking, analytics, external widgets or promotional counters are included.


## Portrait
The portrait is stored at `assets/portrait.jpg`. To replace it later, upload a new image with the same filename.
