# Ricardo Monteiro — academic website

A responsive, animated, single-page academic profile designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example `ricardo-monteiro-website`).
2. Upload **all files and folders** in this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will be shown in the Pages settings.

The website is plain HTML, CSS and JavaScript: no build tools, package installation or server required.

## Personalise before publishing

- The full CV is included as `Ricardo-Monteiro-CV-October-2026.docx` and linked from the page.
- The contact email is set to `ricardo.monteiro@iusspavia.it`.
- Google Scholar and Scopus links currently point to their general landing pages. Replace them with your personal profile URLs.
- No portrait was included in the supplied CV, so the design uses an abstract engineering-inspired graphic instead.
- Bibliometric metrics and selected content reflect the CV dated October 2026. The publications shown on the website are a curated selection; the complete list remains in the downloadable CV.
